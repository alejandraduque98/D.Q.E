# D.Q.E

Este repositorio contiene el código fuente del portafolio personal de Alejandra Duque, desplegado en https://dqe-by-alejandra-duque.netlify.app/
.
Este proyecto fue diseñado y desarrollado completamente por mí, cubriendo todo el proceso: diseño en Figma, creación de elementos en Photoshop y programación frontend.

![Portada de protafolio](../PORTAFOLIO-DQE/src/Assets/IMG/PROYECTOS/PORTAFOLIODQE/PotardaDQE.png)
## Visión general del proyecto

Este portafolio fue creado para:

- Mostrar mis habilidades como diseñadora UI/UX y frontend.

- Presentar proyectos relevantes con interacción y estilo propio.

- Tener una presencia web profesional y funcional.

- Exhibir diseño responsive y buenas prácticas de código.

El proyecto esta organizado con un sistema de diseño claro para garantizar consistencia visual y facilidad de mantenimiento.

## Archivos en PSD

Antes de pasar al navegador, varios elementos visuales se trabajaron en Photoshop (PSD):

- Imágenes de cabecera y presentación

- composiciones visuales

- Recursos gráficos exportados a formatos web
